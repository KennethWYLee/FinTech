# Artificial Intelligence in FinTech

This directory contains the public, student-facing materials for the 18-week course. Week 1 turns an investment idea into a testable quantitative trading question. The course then progresses from financial data to technical indicators and features, signals, backtesting, machine-learning prediction, trading costs, performance evaluation, and basic portfolio weighting before Report 1. Later paper weeks discuss papers related to weighting methods.

The [complete syllabus](../README.md) contains the learning outcomes, weekly schedule, assessment, submission, version, comparison, and accommodation rules. All weekly main files are directly available in this directory. Week 1 uses one instructional Markdown file, and Weeks 2 through 8 each use one complete executable notebook containing the main lesson and its supporting information. When a later week needs a separate support file, that file is placed beside its main file. The bilingual [course statement and GenAI policy](GenAI使用規範.md) apply throughout the semester.

The [Week 2 environment and data check](resources/notebooks/00_Colab_課前環境與資料檢查.ipynb) is an optional preparation notebook. The [Week 2 main notebook](week2_main.ipynb) integrates preparation, the complete lesson, worked issues, independent practice, an integrated case, troubleshooting, extensions, and sources. Weeks 3–8 follow the same overall issue-based standard while addressing their own topics; use the weekly links in the table above rather than treating one notebook as a substitute for another. The four notebooks whose filenames begin with `01_TypeB` through `04_TypeB` preserve earlier optional examples that combine topics now assigned to several weeks; they do not replace the current weekly main files or define current assessment requirements. Instructor answers, grading records, administrative files, personal EMI documents, and material without verified distribution rights are not included.
