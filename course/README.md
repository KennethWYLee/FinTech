# Artificial Intelligence in FinTech

This directory contains the public, student-facing materials for the 18-week course. The course progresses from financial data to backtesting, performance evaluation, and portfolio weighting.

## Weekly materials

| Week | Topic |
|---|---|
| [Week 1](week1/) | Course orientation, assessment, learning outcomes, and computing environment |
| [Week 2](week2/) | Financial prices, returns, and data frequency |
| [Week 3](week3/) | Point-in-time information, financial features, and simple signals |
| [Week 4](week4/) | Construction of a basic backtest |
| [Week 5](week5/) | Rolling, expanding, and walk-forward evaluation |
| [Week 6](week6/) | Model updating, signal updating, and portfolio rebalancing |
| [Week 7](week7/) | Trading costs, execution assumptions, and benchmarks |
| [Week 8](week8/) | Performance evaluation and backtest auditing |
| [Week 9](week9/) | Asynchronous midterm submission |
| [Week 10](week10/) | Individual short reports and transition to portfolio weights |
| [Week 11](week11/) | Basic portfolio-weighting methods |
| [Week 12](week12/) | Minimum-variance and mean-variance portfolios |
| [Week 13](week13/) | Covariance estimation, risk parity, and diversification |
| [Week 14](week14/) | Downside risk and robust portfolio decisions |
| [Week 15](week15/) | Development and evaluation of student weighting methods |
| [Week 16](week16/) | Final reports, session 1 |
| [Week 17](week17/) | Final reports, session 2 and comparison of other teams |
| [Week 18](week18/) | Advanced issues and research questions |

The complete syllabus is in [Week 1](week1/1151_智慧金融科技_量化交易研究導向課程大綱.md). Materials are added only after checking that they are student-facing and suitable for public distribution. Instructor answers, grading records, administrative files, personal EMI documents, and material without verified distribution rights are not included.
