# Artificial Intelligence in FinTech

This directory contains the public, student-facing materials for the 18-week course. The course progresses from financial data to backtesting, performance evaluation, and portfolio weighting.

## Weekly materials

| Week | Topic |
|---|---|
| [Week 1](week1/week1_main.md) | Course syllabus, learning outcomes, assessment, and semester expectations |
| [Week 2](week2/week2_main.md) | Financial prices, returns, and data frequency |
| [Week 3](week3/week3_main.md) | Point-in-time information, financial features, and simple signals |
| [Week 4](week4/week4_main.md) | Concept report and construction of a basic backtest |
| [Week 5](week5/week5_main.md) | Rolling, expanding, and walk-forward evaluation |
| [Week 6](week6/week6_main.md) | Model updating, signal updating, and portfolio rebalancing |
| [Week 7](week7/week7_main.md) | Trading costs, execution assumptions, and benchmarks |
| [Week 8](week8/week8_main.md) | Performance evaluation and backtest auditing |
| [Week 9](week9/week9_main.md) | Asynchronous progress-report submission |
| [Week 10](week10/week10_main.md) | Progress-report presentations and transition to portfolio weights |
| [Week 11](week11/week11_main.md) | Basic portfolio-weighting methods |
| [Week 12](week12/week12_main.md) | Minimum-variance and mean-variance portfolios |
| [Week 13](week13/week13_main.md) | Covariance estimation, risk parity, and diversification |
| [Week 14](week14/week14_main.md) | Downside risk and robust portfolio decisions |
| [Week 15](week15/week15_main.md) | Development and evaluation of student weighting methods |
| [Week 16](week16/week16_main.md) | Final report, session 1 |
| [Week 17](week17/week17_main.md) | Final report, session 2 and comparison of other teams |
| [Week 18](week18/week18_main.md) | Advanced issues and research questions |

The complete syllabus is [Week 1 main](week1/week1_main.md). Each weekly directory contains exactly one main file and one support file. The [course statement and GenAI policy](GenAI使用規範.md) applies throughout the semester. Public notebooks are stored in `resources/notebooks/` and linked from the relevant support files. Instructor answers, grading records, administrative files, personal EMI documents, and material without verified distribution rights are not included.
