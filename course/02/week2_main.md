# Week 2 — Financial Data and Returns

Week 2 introduces financial prices, returns, and data frequency. Students calculate simple returns, log returns, cumulative returns, and portfolio returns. The class examines adjusted prices, dividends, stock splits, missing values, trading calendars, and the alignment of variables recorded at different frequencies.

By the end of the week, students should be able to construct a return series from price data, explain the effect of data frequency, and document the main data-processing decisions.
