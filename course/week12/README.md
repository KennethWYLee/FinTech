# Week 12 — Mean-Variance Portfolio Weighting

Week 12 introduces expected returns, covariance estimation, the efficient frontier, minimum-variance portfolios, mean-variance optimization, and maximum-Sharpe portfolios. The class examines how estimation errors can produce concentrated, unstable, or economically implausible weights.

By the end of the week, students should be able to formulate a constrained portfolio problem, compute its weights, and diagnose sensitivity to expected-return and covariance estimates.
