# Week 1 — Course Orientation

Week 1 explains the overall course direction, learning outcomes, assessment structure, and expected student work. The semester progresses from financial data to backtesting, performance evaluation, and portfolio weighting. Students are introduced to the midterm quantitative-trading work, the final portfolio-weighting work, individual technical assessments, English reporting, reproducibility, comparison of classmates' work using evidence, and permitted uses of generative AI.

By the end of the week, students should be able to describe what they will learn, produce, explain, and defend during the semester and confirm that their computing environment can run the course notebooks.
